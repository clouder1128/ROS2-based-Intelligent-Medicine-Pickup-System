# 测试执行手册

## 1 测试指令

### 1.1 搭建环境
```bash
# 进入后端主程序
cd agent_with_backend

# 创建并进入虚拟环境
python3 -m venv .venv
source venv/bin/activate
```
### 1.2 执行测试用例

#### 1.2.1 执行所有测试
```bash
# 执行测试用例
pytest tests/ -v

# 生成 Pytest 测试报告
pytest --html=report.html
```

#### 1.2.2 执行指定测试
```bash
# 执行 unit、integration、agent等测试集
pytest tests/[unit] -v
```

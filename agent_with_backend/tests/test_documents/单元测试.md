# 单元测试设计说明

## 1 测试目标

单元测试旨在验证 ROS2 智能药品拣选系统各核心模块内部函数、类及业务逻辑的正确性。

测试遵循以下原则：

* 仅测试单个函数或类
* 不依赖真实外部系统
* 数据库使用 Mock 或测试数据库
* LLM 接口全部 Mock
* ROS2 节点全部 Mock
* 测试可重复执行
* 测试执行时间小于10秒

测试框架：

```bash
pytest
pytest-cov
unittest.mock
```

```python
import pytest
from datetime import date,timedelta

class Drug:
    def __init__(self,name,stock,expiry):
        self.name=name
        self.stock=stock
        self.expiry=expiry


def update_stock(drug,change):
    drug.stock += change
    return drug.stock


def is_expired(drug):
    return drug.expiry < date.today()


def check_stock(drug,required):
    return drug.stock >= required


def test_update_stock():
    drug=Drug("阿司匹林",100,date.today())

    result=update_stock(drug,-20)

    assert result==80
    assert drug.stock==80


def test_check_stock_success():
    drug=Drug("布洛芬",50,date.today())

    assert check_stock(drug,20) is True


def test_check_stock_fail():
    drug=Drug("布洛芬",10,date.today())

    assert check_stock(drug,20) is False


def test_expired_drug():
    drug=Drug(
        "测试药品",
        10,
        date.today()-timedelta(days=1)
    )

    assert is_expired(drug) is True
```

```python
import jwt
import pytest
from datetime import datetime,timedelta

SECRET="test_secret"


def generate_token(user_id):
    payload={
        "user_id":user_id,
        "exp":datetime.utcnow()+timedelta(minutes=5)
    }

    return jwt.encode(payload,SECRET,algorithm="HS256")


def verify_token(token):
    return jwt.decode(
        token,
        SECRET,
        algorithms=["HS256"]
    )


def test_generate_token():
    token=generate_token(1)

    assert token is not None


def test_verify_token():
    token=generate_token(1)

    payload=verify_token(token)

    assert payload["user_id"]==1


def test_invalid_token():

    with pytest.raises(jwt.InvalidTokenError):
        verify_token("abc")
```

```python
from unittest.mock import Mock


TOPIC_NAME="/task_request"


def create_task():

    return {
        "drug":"阿司匹林",
        "quantity":1
    }


def publish_task(task,publisher):

    try:
        publisher.publish(task)
        return True
    except Exception:
        return False


def test_create_task():

    task=create_task()

    assert task["drug"]=="阿司匹林"


def test_topic_name():

    assert TOPIC_NAME=="/task_request"


def test_publish_success():

    publisher=Mock()

    task=create_task()

    assert publish_task(
        task,
        publisher
    ) is True


def test_publish_exception():

    publisher=Mock()

    publisher.publish.side_effect=Exception()

    task=create_task()

    assert publish_task(
        task,
        publisher
    ) is False
```

# 9 通过准则

满足以下条件则判定单元测试通过：

1. 所有测试用例执行成功；
2. P1缺陷数量为0；
3. P2缺陷数量不超过2个；
4. 总体代码覆盖率不低于85%；
5. 测试执行时间不超过10秒；
6. 所有Mock测试均通过；
7. 测试结果可重复复现。

测试通过后方可进入 API 集成测试阶段。

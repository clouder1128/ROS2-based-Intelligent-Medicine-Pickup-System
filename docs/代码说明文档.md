## 1. 引言

本文档按文件组织结构逐项说明基于 ROS2 的智能药品管理系统的代码构成，详述各组件来源（自主研发、大模型辅助生成、第三方开源、外部资源）及每个文件的用途。

### 1.1 来源分类

| 分类 | 说明 |
|------|------|
| 自主研发 | 开发团队独立编写的代码 |
| 大模型辅助 | 借助大语言模型（Claude/OpenAI）生成并经团队修改后的代码 |
| 二次开发 | 从外部获取的代码资源，根据实际情况修改 |
| 第三方开源 | 开源或商业第三方软件包、库 |
| 外部资源 | 美术资产、三维模型、贴图等非代码资源 |

## 3. agent_with_backend/ — 主后端系统

核心后端服务，提供 Flask HTTP API、AI 医疗 Agent、ROS2 集成、数据库管理、认证授权及 Web 前端界面。

### 3.1 应用入口与配置

| 文件 | 来源 | 说明 |
|------|------|------|
| `main.py` | 大模型辅助 | Flask 应用入口。注册所有蓝图、初始化数据库连接池、启动 ROS2 后台线程及过期药品定时清扫器 |
| `requirements.txt` | 大模型辅助 | Python 依赖清单（Flask、PyJWT、httpx、anthropic、rclpy 等） |
| `Makefile` | 大模型辅助 | 构建脚本，包含 install、run、test、clean 等目标 |
| `conftest.py` | 大模型辅助 | pytest 共享配置与 fixture 定义 |
| `.env.example` | 大模型辅助 | 环境变量模板（LLM_API_KEY、LLM_PROVIDER、HOST、PORT 等） |
| `quick_start.sh` | 大模型辅助 | 一键启动脚本：创建虚拟环境、安装依赖、初始化数据库、启动前后端 |
| `README.md` | 大模型辅助 | 模块级 README |
| `pharmacy.db` | 大模型辅助 | SQLite 主数据库，包含 116 种药品、适应症、症状同义词、用户、订单等表 |
| `tasks.db` | 大模型辅助 | SQLite 任务持久化数据库，供规划器模块使用 |
| `UNITY_CONNECTION.md` | 大模型辅助 | Unity 仿真连接指南 |
| `.gitignore` | 大模型辅助 | 子模块 Git 忽略规则 |

### 3.2 agent/ — AI 医疗助手

LLM 驱动的医疗咨询引擎，支持多轮对话、症状分析、药品推荐及审批提交流程。

#### 3.2.1 引擎层

| 文件 | 来源 | 说明 |
|------|------|------|
| `agent/__init__.py` | 大模型辅助 | 包初始化，导出 MedicalAgent 类 |
| `agent/engine/__init__.py` | 大模型辅助 | 包初始化 |
| `agent/engine/medical_agent.py` | 大模型辅助 | MedicalAgent 主类。实现三阶段工作流引擎（基础信息采集、表单收集、药品匹配），管理迭代循环、工具调用和会话状态转换 |
| `agent/engine/workflows.py` | 大模型辅助 | 工作流状态枚举与阶段管理。定义阶段 A/B/C 状态机及阶段切换逻辑 |

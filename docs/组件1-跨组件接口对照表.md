## 二、对外接口

### 2.1 数据库连接与 Schema

```python
from common.utils.database import get_db_connection, init_database
```

| 接口 | 说明 |
|---|---|
| `get_db_connection()` | 返回 `sqlite3.Connection`，`row_factory=Row`，已启用 `PRAGMA foreign_keys=ON` |
| `init_database()` | 幂等建表/迁移，启动时自动调用 |

**核心表结构**：

| 表 | 关键字段 / 约定 |
|---|---|
| `inventory` | **41 列**；库存用 `quantity`（`stock` 兼容列固定 0）；`expiry_date` 为**剩余天数整数**；`is_deleted` 软删除 |
| `categories` | 13 条种子；`inventory.category = categories.name`（字符串 JOIN，非 FK） |
| `inventory_transactions` | `quantity_change` · `transaction_type`（`in`/`out`/`adjust`/`expire`） |
| `drug_indications` | 26 条基础种子；`drug_id` → `indication` |
| `symptom_synonyms` | 65 条 / 21 个标准词；`standard_term` · `synonym` · `match_type` |
| `order_log` | 组件2 写入 |
| `auth_*` | 组件4 `ensure_auth_schema()` 管理，组件1 不重复建表 |

### 2.6 症状/适应症查询（`symptom_db_service.py`，第 4 周）

```python
from common.utils import get_all_synonyms, find_standard_term, expand_symptom_list, get_drugs_by_symptom, get_drug_indications
```

| 函数 | 返回 | 说明 |
|---|---|---|
| `get_all_synonyms()` | `Dict[str, List[str]]` | 全量 `{标准词: [同义词...]}` — 直接替换 `SymptomService.STANDARD_SYMPTOMS` |
| `find_standard_term(text)` | `Optional[str]` | 任意输入 → 标准词（精确 > 同义词 > 模糊） |
| `expand_symptom_list(syms)` | `List[str]` | 症状列表展开为标准词 + 全部同义词，提高召回率 |
| `get_drugs_by_symptom(sym)` | `List[dict]` | 按症状查药（含同义词展开）；返回带 `indications` 字段的药品列表 |
| `get_drug_indications(drug_id)` | `List[str]` | 单药全部适应症 |

**组件3 接入最小改动：**

```python
# SymptomService._load_symptoms()
from common.utils import get_all_synonyms
self.STANDARD_SYMPTOMS = get_all_synonyms()

# ScreeningService.screening_query() — 缓存优先
from common.utils import get_drug_cache, get_drugs_by_symptom
cache = get_drug_cache()
drugs = cache.get_drug_list(symptom, None, None, 'drug_id', 'asc')
if drugs is None:
    drugs = get_drugs_by_symptom(symptom)
    cache.set_drug_list(symptom, None, None, 'drug_id', 'asc', drugs)
```

### 2.8 文件上传存储（`upload_controller.py`，第 5 周）

```
请求：multipart/form-data，字段名 file
支持类型：jpg / jpeg / png / gif / webp / csv
单文件上限：16 MB
存储路径：agent_with_backend/uploads/（UUID 命名，不进数据库）
```

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/upload` | 上传文件，返回 `file_id` + 访问 URL |
| GET | `/api/upload/<file_id>` | 直接访问/下载文件（浏览器可预览图片） |
| DELETE | `/api/upload/<file_id>` | 删除已上传文件 |

**POST 成功响应（201）：**

```json
{
  "success": true,
  "data": {
    "file_id":      "a3f9c1d2eb4f.png",
    "file_name":    "drug.png",
    "file_size":    24576,
    "content_type": "image/png",
    "url":          "http://host/api/upload/a3f9c1d2eb4f.png"
  }
}
```

**组件2 接入示例：**

```python
# 上传药品图片后，将 url 写入 image_url 字段
import requests
resp = requests.post("http://localhost:8001/api/upload",
                     files={"file": open("drug.png", "rb")},
                     headers={"Authorization": f"Bearer {token}"})
image_url = resp.json()["data"]["url"]

# 上传 CSV 后，可将内容交给 batch-import
resp = requests.post("http://localhost:8001/api/upload",
                     files={"file": open("drugs.csv", "rb")},
                     headers={"Authorization": f"Bearer {token}"})
# resp.json()["data"]["url"] 可供前端展示或后续下载
```

> 权限说明：当前为开放接口（与其他接口对齐）；如需限制，在路由上添加 `@require_permission('manage:upload')` 即可。
